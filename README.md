# 🔗 Nexum — Frontend

> Projeto Integrador · Faculdade  
> Aplicativo de controle financeiro pessoal com foco em experiência do usuário.

---

## 📌 Sobre o projeto

O **Nexum** é uma aplicação web de controle financeiro pessoal que permite ao usuário categorizar gastos, criar orçamentos mensais, visualizar relatórios e receber sugestões personalizadas via inteligência artificial.

Este repositório contém **apenas o frontend** da aplicação.

---

## 🚀 Tecnologias

- [Next.js](https://nextjs.org/) — Framework React
- [TypeScript](https://www.typescriptlang.org/) — Tipagem estática
- [Tailwind CSS](https://tailwindcss.com/) — Estilização
- [Figma](https://figma.com) — Prototipação e Design System

---

## 🎨 Design

O design da aplicação foi desenvolvido no Figma com sistema de componentes e variáveis de estilo.  
As principais telas incluem:

- Landing Page
- Dashboard financeiro
- Controle de gastos
- Planejamento mensal
- Relatórios visuais
- Consultor com IA

## ⚙️ Como rodar localmente

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/nexum-frontend.git

# Entre na pasta
cd nexum-frontend

# Instale as dependências
npm install

# Rode o servidor de desenvolvimento
npm run dev
```

Acesse em: `http://localhost:3000`
